關於我

我目前主要發展方向為 Java 後端工程師，具備企業系統開發與維護經驗。過往工作中使用 Java、Spring Boot、MyBatis、SQLServer、MySQL、Tomcat、Git/GitLab 等技術，參與後端功能開發、資料查詢、報表轉檔、批次處理與系統問題排查。

在銀行相關專案中，我接觸到金融系統對穩定性、資料正確性與資安要求較高的開發流程。專案內容包含報表中心、大量資料下載、CSV/Excel/PDF/TXT 轉檔、SIT/UAT 測試支援與弱點掃描修正。這些經驗讓我理解到後端開發不只是完成 API 或功能，也需要考量資料量、效能、例外處理、log 設計與後續維護。

我也有接觸 RabbitMQ、Redis、Docker、Kubernetes、kubectl、k9s 等技術，雖然部分技術仍在持續累積實務經驗，但已能配合專案需求進行基本操作、問題查詢與開發支援。遇到問題時，我習慣先從錯誤訊息、log、資料庫與程式流程逐步分析，並整理出可能原因與修正方向。

我期望未來能持續加強 Java 後端、Spring Boot、資料庫查詢效能、系統架構與容器化部署能力，成為能穩定交付功能、協助排查問題並持續成長的後端工程師。
