VidsProtect

介紹

VidsProtect 是一個以 Python 開發的本機端影片保護工具， 可將影片檔案進行加密處理，使檔案無法被一般播放器直接開啟。 使用者可透過正確金鑰進行解密， 將受保護的影片還原為可播放狀態。

主要功能

  • 🔐 影片檔案加密：將原始影片轉換為受保護的加密檔案
  • 🔓 影片檔案解密：使用正確金鑰還原影片內容
  • 📁 批次處理影片：可一次處理多個影片檔案，減少重複操作
  • 🛡️ 防止直接播放：加密後的影片無法被一般播放器直接開啟
  • ⚙️ 自動化處理流程：透過 Python 腳本執行加密與解密流程
  • 💻 本機端執行：不需將影片上傳到雲端即可完成處理

專案特色

此專案主要針對影片檔案在本機端保存時， 可能被直接開啟或複製觀看的情境進行設計。 透過檔案加密機制， 影片內容會被轉換為無法由一般播放器直接播放的資料， 使用者完成解密流程後， 才能將內容還原成可播放的影片檔案。

專案實作內容包含 Python 檔案讀寫、 加密與解密處理、金鑰驗證、 批次檔案處理與自動化流程， 作為檔案處理與腳本工具開發的實作專案。
