VidsProtect

介紹

VidsProtect 是一個以 Python 開發的本機端影片保護工具， 可將影片檔案進行加密處理，使檔案無法被一般播放器直接開啟。 使用者可透過正確金鑰進行解密，將受保護的影片還原為可播放狀態。

主要功能

  • 🔐 影片檔案加密：將原始影片轉換為受保護的加密檔案
  • 🔓 影片檔案解密：使用正確金鑰還原影片內容
  • 📁 批次處理影片：可一次處理多個影片檔案，減少重複操作
  • 🛡️ 防止直接播放：加密後的影片無法被一般播放器直接開啟
  • ⚙️ 自動化處理流程：透過 Python 腳本快速執行加密與解密流程
  • 💻 本機端執行：不需要將影片上傳到雲端，降低私人影片外流風險

專案特色

此專案主要解決私人影片檔案在本機端保存時，可能被他人直接開啟或複製觀看的問題。 透過檔案加密機制，影片內容會被轉換為不可直接播放的格式，只有在使用者執行解密流程後， 才能還原成可播放的影片檔案。

此工具適合用於個人影片保存、私密素材保護、教學影片暫存保護等情境。 專案重點不只是單純處理影片，而是結合 Python 的檔案讀寫、加密處理、批次作業與自動化流程。
